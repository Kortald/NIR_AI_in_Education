# Система ИИ в образовании: прогноз числа должников магистрантов

Научно-исследовательская работа. Система прогнозирует, будет ли у магистранта академическая задолженность в следующем семестре, и считает число должников по группам «учебный план × семестр». Испытания проводятся по методике ГОСТ Р 70946-2023 (показатели Qc и Qa) на демонстрационном наборе данных из приложения к ГОСТ Р 72391-2025 (п. 6.1 а, 6.2 а).

## Что внутри

```
nir_code/
  main.py        полный запуск: данные, эксперименты, таблицы и графики в results/
  config.py      пути, определение должника, параметры экспериментов
  src/           загрузка и подготовка данных, признаки, модели, показатели Qc и Qa, графики
  tests/         автоматические тесты (20 проверок)
  results/       таблицы (csv), графики (png) и сводка по данным (facts.json)
```

Модели: логистическая регрессия на градиентном спуске, написанная с нуля; та же регрессия из scikit-learn; случайный лес; градиентный бустинг. Для сравнения используются два базовых правила: «константа» (мажоритарный класс) и «повтор прошлого семестра».

Схема проверки: кросс-валидация по студентам (5 блоков × 3 повтора), порог решения подбирается по Qc внутри обучающей части, доверительные интервалы строятся бутстрэпом по студентам, отдельно есть проверка по времени (обучение на семестрах 1–2, тест на семестре 3) и проверка калибровки вероятностей.

## Запуск

Нужен Python 3.10 или новее.

```
pip install -r requirements.txt
cd nir_code
python3 main.py
python3 -m pytest tests
```

Данные в репозиторий не входят. Файл `ГОСТ Р 72391-2025 приложение.xlsx` нужно положить в папку `Сборник файлов/` рядом с `nir_code/`, то есть так:

```
Сборник файлов/ГОСТ Р 72391-2025 приложение.xlsx
nir_code/
```

При первом запуске xlsx читается долго и сохраняется в кэш `nir_code/data/raw_cache.pkl`, дальше используется кэш.

## Результаты

Все цифры воспроизводятся запуском `main.py` и лежат в `nir_code/results/`.

- Постановка «все студенты» (4 598 пар «семестр t → t+1»): лучшие системы получают «соответствие» по Qc (случайный лес 1,409), но не лучше правила «повтор прошлого семестра» (1,398).
- Постановка «новые должники» (студенты без долга в семестре t): «несоответствие» у всех систем, лучшая Qc 0,963.
- Число должников по группам: суммарный прогноз 260–261 при факте 263, Qa около 1,89–1,91 («высокое соответствие»).
- Вероятности долга откалиброваны: ECE не больше 0,011, сумма прогнозов 397,6–399,3 при фактических 399.
